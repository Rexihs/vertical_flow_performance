<!-- Программа для расчёта VFP и UDT таблиц -->
Программа предназначения для быстрого расчёта VFT таблиц по скважинам, так же с возможностью расчёта таблиц в формате UDT с целью управления скважинами. Таблицы создаются в формате Eclipse для последующей загрузки в гидродинамическую модель.
